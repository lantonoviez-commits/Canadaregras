---

## 🚀 Como publicar no GitHub Pages (Passo a Passo)

1. Crie um repositório no seu GitHub (ex.: `canada38-regras`).
2. Adicione os arquivos `index.html` e a imagem `canadaaaaa.jpg` na raiz do repositório.
3. No repositório no GitHub, acesse a aba **Settings** (Configurações).
4. No menu lateral esquerdo, clique em **Pages**.
5. Na seção **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
6. Clique em **Save**.
7. O GitHub gerará o link público do portal em instantes:  
   `https://seu-usuario.github.io/canada38-regras/`
